Privacy Policy – Highlight-Studio

  • Highlight-Studio runs locally on the developer's own Windows computer. There is no server and no user database.
  • Data received from TikTok: the basic profile information of the connected account (display name, avatar) and an access token. It is used only to show which account is connected and to upload videos the developer selected.
  • The access token is stored encrypted on the developer's computer (Windows DPAPI) and is never shared with third parties, sold or used for advertising.
  • No data from other TikTok users is collected.
  • The connection can be removed at any time in the tool and in the TikTok app settings (Security → Manage app permissions). This deletes the stored token.
